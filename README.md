# My Travel Blog - A simple travel blog built with HTML and CSS. It's a work in progress, but it's a start! #my-travel-blog #forst

This is a simple travel blog built with HTML and CSS. It's a work in progress, but it's a start!

## Features

- A responsive design that looks great on desktop and mobile devices
- A clean and simple layout that makes it easy to read and navigate
- A brief overview of some of the amazing places I've been to
